# 2.1.0

本版本包含完整的深色模式，支持深色、浅色和跟随系统，自动保存外观选择。

- 主界面、域名表格、输入框、下拉菜单、滚动条、状态提示与托盘菜单均适配主题。
- 保留 Steam 节点自动验证、域名规则编辑、手动停止、关闭后恢复和最小化到托盘等功能。
- 发布包内置 Node.js v24.22.1，并附完整第三方授权。

## 安装包

- `SteamSmart-2.1.0-windows-x64.zip`：推荐下载，包含 EXE、使用说明与第三方授权。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

安装包附在 GitHub Releases，不作为源码文件提交。

## 验证

深色模式在 Windows 上完成主题切换、重开记忆、表格编辑、弹层及布局验证，共 85 项断言通过；验证未启动真实下载转发，系统 hosts 与下载配置保持不变。
